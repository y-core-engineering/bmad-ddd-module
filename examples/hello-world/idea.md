# Idea: Hello World

## What it is about

A simple program that is called from the shell and prints `hello world`.

## Who uses it

A person who starts the program in a terminal.

## Flow

1. The person calls the program from the shell.
2. The program prints `hello world` to standard output.
3. The program ends.

## Result

The line `hello world` appears in the shell.

## Not part of the idea

- input or parameters
- a graphical interface
- connection to other systems
